Download `Yuzu-Nintendo-Free.zip` (~50 MB) and extract with WinRAR or 7-Zip. **No password.**

### Step 2 — Add Keys
Open the `/keys` folder and copy `prod.keys` inside. Do not rename the file.

### Step 3 — Install Firmware
Open Yuzu, go to **File → Install Firmware**, and select the firmware ZIP.

### Step 4 — Configure Graphics
